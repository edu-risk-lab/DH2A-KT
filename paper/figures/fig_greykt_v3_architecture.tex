\caption{GreyKT-v3: reliability-aware hybrid knowledge tracing. The black-box
branch (DH2-KT, unmodified) and a white-box branch (a zero-learned-parameter
Beta-Binomial prerequisite-mastery estimator read directly off P0's audited
$E_{\mathrm{pre}}$) each produce a probability and a confidence. A non-learned
relative-reliability gate $g_B=C_B/(C_B+C_W+\epsilon)$ weights the two
branches' probabilities directly in probability space, so $g_B$ is an
inspectable audit trail for every prediction rather than an opaque blend.
When $C_B\gg C_W$, $g_B\to1$ (the black-box branch is trusted); when
$C_W\gg C_B$, $g_B\to0$ (the white-box branch is trusted); when $C_B=C_W$,
$g_B=0.5$ exactly (genuine shared uncertainty, unlike a $\min(\cdot)$-based
floor, which would not distinguish this case from either branch alone being
weak). All quantities other than the black-box branch's own parameters are
fixed statistics or config constants, not learned via backpropagation.}
